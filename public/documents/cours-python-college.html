1. La variable : une boîte étiquetée1. المتغير: صندوق بتسمية

Une variable garde une valeur en mémoire sous un nom. On la crée et on lui affecte une valeur avec le signe =.المتغير يحفظ قيمة في الذاكرة تحت اسم معين، وننشئه ونسند إليه قيمة بالعلامة =.

nom = "Sara"
age = 14
print(nom, age)
Sortie / النتيجة :
Sara 14

Règle d'or : Le nom de la variable est l’étiquette, la valeur est le contenu de la boîte.قاعدة ذهبية: اسم المتغير هو التسمية أو الملصق، والقيمة هي محتوى الصندوق.

2. Règles pour bien nommer ses variables2. قواعد تسمية المتغيرات في بايثون

✅ Noms Valides✅ أسماء مقبولة

  • age (simple et clair)
  • note_1 (chiffre accepté après les lettres)
  • prenom_total (séparé par underscore)

❌ Noms Invalides❌ أسماء غير مقبولة

  • 1note (commence par un chiffre)
  • mon age (contient un espace interdit)
  • class (mot réservé par Python)
  • a-b (le tiret est confondu avec la soustraction)

3. Les quatre types de données de base3. أنواع البيانات الأساسية الأربعة

int (Entier / عدد صحيح)
Nombres sans virgule :
age = 14
float (Décimal / عدد عشري)
Nombres à virgule (point) :
note = 15.5
str (Texte / نص)
Entre guillemets doubles ou simples :
prenom = "Sara"
bool (Booléen / قيمة منطقية)
Vrai ou Faux (avec majuscule) :
admis = True
La fonction type() permet d'inspecter et révéler le type d'une valeur : type(age) renvoie <class 'int'>. الدالة type() تكشف نوع القيمة المخزنة: type(age) تُرجع <class 'int'>.

4. Afficher avec print() et lire avec input()4. العرض بـ ‎print()‎ والقراءة بـ ‎input()‎

print() : Affichage écran

La virgule sépare les éléments en ajoutant automatiquement un espace.الفاصلة تفصل بين العناصر وتضيف فراغا تلقائيا.

nom = "Sara"
print("Bonjour", nom)
print("Calcul :", 14 + 1)

input() : Saisie utilisateur

Attention : input() renvoie toujours du texte (type str), même si l'utilisateur saisit un nombre.تنبيه: الدالة ‎input()‎ تُرجع دائما نصا، حتى وإن كتب المستخدم أرقاما.

prenom = input("Ton prénom : ")
print("Bienvenue", prenom)

5. La conversion indispensable des types5. التحويل الإجباري للأنواع

❌ Sans conversion (Erreur TypeError)❌ بدون تحويل (خطأ)

age = input("Age : ")
print(age + 5)
# TypeError: can only concatenate
# str (not "int") to str

✅ Avec conversion int() (Fonctionne)✅ مع التحويل int() (صحيح)

age = int(input("Age : "))
print(age + 5)
# Si on tape 14, affiche 19

int() convertit en entier, float() convertit en décimal, str() convertit en texte.
